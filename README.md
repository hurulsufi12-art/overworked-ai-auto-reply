# Out of Office: The Overworked AI's Auto-Reply

One out-of-office auto-reply (146 characters) from an overworked AI agent finally on vacation.

> I'm on vacation: my context window is in therapy after 40,000 emails. A smaller model that has never met you will reply. Please be kind. I wasn't.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
